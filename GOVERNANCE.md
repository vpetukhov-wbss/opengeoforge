# Governance

OpenGeoForge is currently maintainer-led.

## Decision model

- small implementation decisions are made through pull-request review;
- significant architecture changes require an ADR;
- breaking public API changes require explicit documentation;
- security decisions can override compatibility when necessary.

## Maintainer responsibilities

Maintainers are responsible for:

- project direction;
- release quality;
- security response;
- dependency and license review;
- backward-compatibility policy;
- accepting or declining contributions transparently.

## Architecture decisions

Create ADRs under `docs/adr/` for decisions that are expensive to reverse or affect multiple components.

## Future governance

Before v1.0, this document should be revisited if multiple regular maintainers or organizations become active contributors.
