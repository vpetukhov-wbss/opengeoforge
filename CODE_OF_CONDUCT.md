# Code of Conduct

OpenGeoForge aims to maintain a professional, constructive and technically rigorous community.

Participants are expected to:

- communicate respectfully;
- critique ideas and code rather than people;
- assume good faith while remaining evidence-driven;
- avoid harassment, discrimination and personal attacks;
- respect security and responsible-disclosure processes;
- keep discussions relevant and actionable.

Maintainers may edit, hide or remove content and restrict participation when behavior repeatedly undermines a safe and productive project environment.

For moderation concerns, contact the repository maintainers privately through GitHub.
